# MemAgent: 多轮 Agent 的指代感知记忆系统

> 一款基于 **Redis (工作记忆)** + **PostgreSQL/pgvector (情景&语义记忆)** + **轻量实体指代消解** + **记忆遗忘衰减机制** 的高质量 Agent 记忆框架，具备开箱即用的离线评估体系。

---

## 🌟 项目亮点

1. **三层记忆架构**：按需检索，避免每轮对话全量注入历史 Token，大幅降低延迟与费用。
2. **实体打分与指代解析**：解决多轮对话中“它、那个、第一个、改一下地址”等指代歧义。
3. **记忆动态衰减与冲突覆盖**：基于重要度打分（明示偏好 > 工具结果 > 闲聊）与指数时间衰减，实现记忆库自我瘦身与更新。
4. **全链路真实离线评估**：内嵌 200 条多轮指代任务集，包含指代准确率、任务完成率、记忆命中率、冗余率与 Token 消耗对比评估。

## 🏗️ 系统架构与数据流

```
                             +--------------------+
                             | Streamlit 前端 / API |
                             +---------+----------+
                                       |
                           +-----------v-----------+
                           |  Agent 对话主控 (Chat) |
                           +-----------+-----------+
                                       |
      +--------------------------------+--------------------------------+
      |                                |                                |
+-----v--------+             +---------v--------+             +---------v--------+
|  指代解析层  |             |   三层记忆检索   |             | 记忆更新/遗忘策略|
+--------------+             +------------------+             +------------------+
                                       |
           +---------------------------+---------------------------+
           | Working Memory            | Episodic Memory           | Semantic Memory
           | (Redis - 近N轮)           | (pgvector - 摘要向量)     | (PostgreSQL - 事实偏好)
           +---------------------------+---------------------------+
```

## 🚀 快速开始

### 1. 启动基础设施 (PostgreSQL + Redis)

```bash
docker compose up -d
```

### 2. 配置环境变量

复制 `.env.example` 并重命名为 `.env`，填入你的 LLM API Key：

```bash
cp .env.example .env
```

### 3. 安装依赖与运行

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
```
